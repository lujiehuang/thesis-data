# Thesis data and analysis materials

Author: Lujie Huang

## Public package / 公开资料包

[Download the organized public package (2026-10-07)](论文数据公开资料包_20261007.zip)

The ZIP contains questionnaire data, variable dictionaries, SEM/fsQCA/NCA analysis materials, historical versions, and version notes. Extract it before following the folder paths below.

| Folder inside the ZIP | Contents |
|---|---|
| `01_data` | Main questionnaire data (413 records, 31 substantive items) and separate pilot data, with codebooks |
| `02_sem` | SEM models, saved outputs and source tables |
| `03_fsqca` | Construct scores, calibration versions and saved solutions |
| `04_nca` | Saved R workspace, saved-run summary, bottleneck table and figures |
| `06_history` | Explicitly labeled historical design and result files |

Read `README.md` and `VERSION_NOTES.md` inside the package before using the data. All 413 main-source rows and retained response values are preserved. Open-response and selected export metadata fields are excluded from the public copy. Version notes identify the specific screening-field and calibration differences still requiring reconciliation; packaging does not resolve those differences.
